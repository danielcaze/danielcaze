### what I do

Full-stack software engineer, five years in. I build product features across web, mobile and
backend: REST APIs and microservices in NestJS and Fastify, Angular and React front ends,
React Native apps, and the cloud plumbing around them on GCP and Azure. Tests first, gated in
CI, deployed weekly.

Rewrote a multi-database access layer in Go once, concurrent queries plus index tuning, and
took a panel from 30-40s down to 4-5s. That is still my favourite kind of work.

AI shows up in the mix too: LLM pipelines, transcription and content workflows, internal
tooling, always with a human review step at the end.

### currently shipping

**[saara](https://github.com/danielcaze/saara)** — desktop app that imports photos from an SD
card, clusters them into events by timestamp, and syncs to a local folder or Google Drive with
resumable uploads. Electron + Vite + TypeScript.

**[whatsapp-transcribe-bot](https://github.com/danielcaze/whatsapp-transcribe-bot)** — WhatsApp
bot that transcribes voice notes back into the same chat. Cloudflare Workers + WhatsApp Cloud
API + Groq Whisper, fully serverless. (WIP — paused on a phone-number blocker.)
